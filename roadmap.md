# Cairn roadmap

> Generated from the [Cairn Roadmap GitHub Project](https://github.com/users/ehussong/projects/6) on 2026-07-31. The Project is authoritative.

## Vision

Cairn gives an external LLM one provenance-rich query surface over a personal corpus. The current product is a read-only Router over existing sources; a full corpus Store remains gated by evidence that routing alone cannot solve custody, duplication, portability, or platform lock.

## Pillars

- **Reliable retrieval:** normalized, source-backed results with stable identity and explicit provenance.
- **Connected sources:** one query contract across local files, Logseq, and selected API- or MCP-backed systems.
- **Safe evolution:** read and write capabilities stay separate; future mutation is previewable, auditable, and conflict-aware.
- **Gated custody:** Store work preserves durable links, rebuildability, and archive truth, but begins only after an evidence-backed go decision.

## Now / Next / Later

These are migration proposals, not owner-approved priorities.

- **Now:** validate canonical cross-source queries and harden normalized ranking, grouping, deduplication, and fanout.
- **Next:** set the Router performance threshold, connect DEVONthink/Fastmail/Readwise, and finalize the safe mutation-target contract.
- **Later:** implement audited writes and decide whether evidence justifies the deferred Cairn Store phases.

See the [live Project](https://github.com/users/ehussong/projects/6) for current status, dependencies, milestones, and owner-set priority.
